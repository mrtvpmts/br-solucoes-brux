## 🚀 Sobre o Projeto

Este projeto é uma plataforma premium desenvolvida para a **BR Soluções**, focada em apresentar excelência em logística e produtos industriais através de uma experiência digital moderna e imersiva. O site combina performance de ponta com visualizações 3D interativas para elevar a percepção de valor da marca.

## ✨ Funcionalidades Principais

- **Visualização 3D**: Renderização de produtos (galões e cortinas fluidas) utilizando WebGL/Three.js para uma experiência imersiva.
- **Catálogo Inteligente**: Navegação fluida entre segmentos e categorias de produtos.
- **Arquitetura Responsive-First**: Adaptabilidade total para todos os tamanhos de tela com foco em mobile-first.
- **Animações de Alta Performance**: Utilização de GSAP e Framer Motion para transições suaves e micro-interações premium.
- **Gestão de Leads**: Integração com Supabase para armazenamento seguro de contatos e pedidos de orçamento.
- **SEO & Performance**: Configurações avançadas de Next.js meta-tags, sitemap e otimização de fontes.

## 🛠️ Stack Tecnológica

### Core

- **Next.js 16 (App Router)**: Framework React para produção.
- **React 19**: Biblioteca UI de última geração.
- **TypeScript**: Tipagem estática para robustez do código.

### Estilização & UI

- **Tailwind CSS 4**: Estilização utilitária moderna.
- **Lucide React**: Conjunto de ícones vetoriais.
- **Framer Motion & GSAP**: Motores de animação de alto nível.

### 3D & Gráficos

- **Three.js**: Engine 3D para o navegador.
- **@react-three/fiber & @react-three/drei**: Ecossistema React para Three.js.

### Backend & Serviços

- **Supabase**: Backend-as-a-Service para banco de dados e autenticação.
- **Resend**: Serviço moderno de envio de e-mails transacionais.

## 📦 Estrutura do Projeto

```text
src/
├── app/          # Rotas e layouts (Next.js App Router)
├── components/   # Componentes modulares e reutilizáveis
├── lib/          # Configurações de serviços (Analytics, Supabase)
├── data/         # Mock data e constantes do projeto
└── public/       # Ativos estáticos (Imagens, Modelos 3D, Mockup)
```

## 🏁 Como Começar

1. **Clone o repositório:**

   ```bash
   git clone [url-do-repositorio]
   ```

2. **Instale as dependências:**

   ```bash
   npm install
   ```

3. **Configure as variáveis de ambiente:**
   Crie um arquivo `.env.local` baseado no `.env.local.example`.

4. **Inicie o servidor de desenvolvimento:**

   ```bash
   npm run dev
   ```
